# Susie64 QLD / XLD4 plugin

## Introduction

This software is a Susie x64 plugin for QLD / XLD4 format images.


## Thanks

The Susie interface layer shares code with `ifpi`, which is based on MIYASAKA Masaru's Susie32 Pi Plug-in.

The QLD / XLD4 decoder is an independent implementation based on analysis of [xgload](https://www.vector.co.jp/soft/unix/art/se004440.html) and q4toppm, other publicly available implementations.
